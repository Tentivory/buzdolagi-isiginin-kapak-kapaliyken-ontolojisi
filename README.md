# Buzdolabı Işığının Kapak Kapalıyken Ontolojisi

> **Resmi unvan:** Ulusal Kapalı Kapak Varlık Enstitüsü  
> **Kısa ad:** UKKVE  
> **Slogan:** *Görmediğin ışık, gördüğün karardan daha gerçektir.*

Bu yazılım, insanlığın en eski felsefi krizini çözer:  
**Buzdolabı kapağını kapattığında içerideki lamba söner mi?**

Cevap bilimsel değildir. Cevap **tutanaktır**.

## Bu proje ne yapar?

1. Sana ciddi ciddi kapak durumunu sorar.
2. Işığın ruh halini tahmin eder.
3. Üç hakimli bir ontoloji mahkemesi kurar.
4. Karar yazar. İtiraz yolu yoktur çünkü kapak zaten kapanmıştır.
5. Copilot'a selam çakar. Copilot içeride midir, dışarıda mıdır, o da ayrı bir dosyadadır.

## Kurulum

```bash
python3 ontoloji.py
```

Bağımlılık yoktur. Evren yeterince bağımlıdır.

## Kullanım örneği

```
Kapak durumu? (acik/kapali): kapali
Gözlemci içeride mi? (evet/hayir): hayir
```

Mahkeme toplanır. Işık hakkında 400 kelimelik resmi karar çıkar.  
Kararın özeti: *Işık sönmüş olabilir. Sen emin olamazsın. Enstitü emindir.*

## Bilimsel dayanak (uydurma)

- Schrödinger'in buzdolabı deneyi (1926, hiç yapılmadı)
- Kapalı kapak teoremi (Madde 7/A)
- Gözlemci yoksa lamba da yok mudur, yoksa lamba gözlemciyi mi gözler?
